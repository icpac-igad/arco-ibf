### Why the tail node matters here

The ECMWF ensemble-mean `P_heavy` = 1% → discretises to **Very_Low** → rule-based systems
score this as benign. But the pixel-p95 of `ens_max / 2yr-RP` = **1.11** — meaning the worst
ensemble member already exceeds the return-period threshold in at least one Nairobi pixel.
Rule T1 fires: *wet antecedent + moderate tail risk + low mean exceedance* → pushes risk to
`[0.09, 0.35, 0.46, 0.09, 0.01]`, crossing the Assess threshold P(Mod∪High∪Extreme) = 0.55 ≥ 0.40.

## CPT Structure

The `risk_level` node (5 states: Minimal → Extreme) is conditioned on 5 evidence parents.
All parent states carry soft evidence via Pearl virtual-evidence channels.

| Node | States | Key threshold | Source |
|------|--------|--------------|--------|
| `antecedent` | Dry / Normal / Wet / Very_Wet / Saturated | &lt; 10 / 30 / 60 / 100 mm/7d | IMERG 7-day sum |
| `exceedance_prob` | Very_Low → Very_High | P_heavy bins 0.2 / 0.4 / 0.6 / 0.8 | ECMWF ensemble mean |
| `spatial_coverage` | Localized / Moderate / Widespread | &lt; 30 % / 60 % of pixels | hotspot_fraction |
| `rainfall_trend` | Decreasing / Stable / Increasing | ± 2 mm/d on 7-d regression | IMERG slope |
| `tail_risk` | Nil / Low / Moderate / High | ens_max/RP ratio &lt; 0.5 / 1.0 / 2.0 | pixel p95 |

**Expert rules** (excerpt — tail-risk rules T1–T3 are specific to this upgrade):

- **Rule 1**: Saturated + High/VHigh exceedance + Increasing trend → `[0, 0, 0.05, 0.20, 0.75]`
- **Rule T1**: Moderate tail + wet antecedent + low mean exceedance → `[0.05, 0.20, 0.45, 0.25, 0.05]`
- **Rule T2**: High tail + Very_Low exceedance → `[0.05, 0.20, 0.40, 0.30, 0.05]`
- **Rule T3**: Moderate tail + Increasing trend + low exceedance → `[0.05, 0.15, 0.45, 0.30, 0.05]`

CRMA cost-loss rule (γ = 0.20):

```
Actionable_Risk : P(High) + P(Extreme)              ≥ 0.20
Assess          : P(Mod) + P(High) + P(Extreme)     ≥ 0.40
Evaluate        : P(Low) + P(Mod) + P(High) + P(Ex) ≥ 0.30
Monitor         : otherwise
```
