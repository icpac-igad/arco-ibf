# Rivers Project

A brief overview of the East Africa hydrography processing and TiPg server deployment project.

## Python Scripts

- **process_east_africa_minimal.py** - Core processing script for East Africa hydrography data
- **resume_ea_upload_v2.py** - Resume functionality for East Africa data upload operations
- **wsgi_app.py** - WSGI application for web server deployment

## Visualization

- **river_network_visualization.html** - Interactive visualization of river network data
- **.replit** - Replit deployment configuration for serving the HTML visualization

## Documentation

- **EAST_AFRICA_HYDROGRAPHY_PLAN.md** - Planning document for East Africa hydrography project
- **EA_TABLE_MANAGEMENT.md** - Table management strategies and procedures
- **IMPLEMENTATION_SUMMARY.md** - Summary of implementation details and progress
- **PROCESSING_SUMMARY.md** - Overview of data processing workflows and results
- **UPLOAD_INSTRUCTIONS.md** - Step-by-step instructions for data upload procedures
